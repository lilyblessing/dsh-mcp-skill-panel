## 一、 三大核心决策点论证与裁决

### 决策点 1：变更日志（Changelog）的处理机制
- **方案选项**：
  - A. 留在 README 尾部使用 `<details><summary>` 折叠
  - B. 完整剥离至根目录独立文件 `CHANGELOG.md`，README 仅留外链与版本徽标（**推荐**）
- **深度分析与裁决**：
  - **采纳方案 B**。
  - **核心理由**：
    1. **源码体积与传输负载**：折叠区（`<details>`）虽然在渲染后视觉上收起，但其**字符与体积仍 100% 存在于 README 源码中**。目前变更日志占了 151 行（近 20KB），导致 GitHub 页面初始 DOM 庞大，npm 网页端渲染卡顿甚至折叠失效。
    2. **开源生态惯例**：无论是 `deepseek-ai/deepseek-harness`、`tt-a1i/archify` 还是 `modelcontextprotocol/typescript-sdk`，没有一个成熟项目在 README 堆砌跨越 10 个版本的历史日志。`archify` 更是通过版本徽章 `[![version](...)](CHANGELOG.md#anchor)` 直达指定版本，极其优雅。
    3. **维护分离**：版本发布时，发版脚本/CI 只需往 `CHANGELOG.md` 追写，不污染 README 的主结构。

---

### 决策点 2：深度设计与原理解析（Deep Design）的迁移边界
- **方案选项**：
  - A. 全量保留在 README 并压缩文字
  - B. README 仅保留「高阶结论 + 极简形态对比」，所有实现细节、时序图、历史事故复盘整段迁入 `docs/`（**推荐**）
- **深度分析与裁决**：
  - **采纳方案 B**。
  - **具体分流边界规划**：
    1. **「两种形态」与 AI 中间层**：README 仅保留形态 1（原生直用）与形态 2（中间层按需拉起）的双向切换状态图与三句话定位；复杂的每回合 `system-prompt/assemble` Waterfall 过滤器、源码方法调用图下沉至 `docs/design-mcp-control.md`（已有该文件，扩充整合）。
    2. **「生效时机」与 Prompt Cache**：README 仅保留核心结论（「想省钱选下次生效，急用选立即生效」），把前缀命中与 5~12.5 倍计费倍率的技术测算整段迁入新文档 `docs/prompt-cache.md`。
    3. **「工作原理」与 0.1.x 历史事故**：README 彻底删除对 `PresetTree` 句柄、WeakMap 模块私有实例失联、0.1.x 预设重挂事故等内部实现探讨，全部归档迁入 `docs/internals.md`。
    4. **「验证清单」**：属于 QA 测试用例表，整段迁入 `docs/qa-checklist.md`。
    5. **「已知限制」**：精简保留 3~4 条影响最终用户日常操作的限制，其余关于 `middleLayerHides` 口径计算、无鉴权端点单飞锁死等运维细节迁入 `docs/troubleshooting.md`。

### 决策点 3：多语言命名规范与维护关系
- **方案选项**：
  - A. 维持现状：`README.md` 为中文，`README.en.md` 为英文
  - B. 遵循 GitHub 国际规范：`README.md` 设为英文（面向全球），中文重命名为 `README.zh-CN.md`（**推荐长期方向**）
- **深度分析与裁决**：
  - **评估考量**：
    1. DSH 本身虽为 DeepSeek 社区项目，但其官方仓库 `deepseek-ai/deepseek-harness` 已经全面贯彻「根目录 `README.md` 为英文、`README.zh.md` 为中文」的国际化准则。
    2. `morluto/rea`（32.9 万星）和 `tt-a1i/archify`（8.5 万星）同样均采用 `README.md` 英文主文档。
  - **过渡与执行建议**：
    - **本次交付**：由于本仓库当前中文文档信息最完整，本次直接起草**重构版中文草案**（产物命名为 `03-README草案.md`），并提供中英章节映射表。
    - **落地推荐**：建议作者在后续落地时，将本草案作为 `README.zh-CN.md`，并将翻译后的英文作为根目录 `README.md`；若作者短期仍坚持中文为主，则保留为 `README.md`，但顶部必须统一设置标准双语切换锚点：`**中文** · [English](README.en.md)`。
